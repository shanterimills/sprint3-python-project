# Video Game Sales Analysis

## Description
This project analyzes video game sales data and explores trends in the video gaming industry.

## Data Source
Dataset supplied as part of Python Foundations Sprint Project.
The dataset contains information about some of the best-selling video games of all time, including sales figures, genre, platform, publisher and release year.

## Methods and Tools
- Python
- Functions
- Lists
- Loops
- Conditional Statements
- Dictionaries

## Key Findings
- Wii Sports is the top-selling game with global sales of $82.74M.
- North America sales exceed Japan sales for many of the top selling games in the dataset.
